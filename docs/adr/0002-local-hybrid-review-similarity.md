# ADR 0002：使用本機混合模型找出相似評論候選

## 狀態

已採用；複核等級另依 ADR 0003 的證據模型 v2 決定。

## 決策

評論相似度採中文字符比對與 `multilingual-e5-small` 語意向量的混合分析，並在 OCI ARM64 主機以低優先序離線批次執行，不將評論文字傳送至外部 AI 服務。相似度只負責產生候選，不直接證明協同行為。

候選採完整連結分群，兩個子群只有在所有應比較的跨群成員組合都達門檻時才合併，避免單一橋接評論造成鬆散群組。分析結果以原子快照保存，只有完整成功的批次才成為網頁資料來源，使模型失敗不影響 Google Maps 監控、Telegram 通知或上一批可用結果。

## 後果

- 評論文字保留在本機，結果可由模型版本、門檻及快照重現。
- 完整連結會犧牲部分召回率，以換取群組內的一致性與較低的橋接誤判。
- 文字模型再大也不能從公開文字本身證明付費或受託；行為佐證與資料限制由證據模型另行處理。
- 在 2 CPU 主機上仍需控制執行優先序；模型失敗時保留上一份完整快照。
