# ADR 0001：於監控主機提供 Tailnet 內的動態展示頁

## 狀態

已採用。

## 背景

監控程式已在 Ubuntu 主機上保存 SQLite 評論資料與評論附帶媒體。使用者需要依店家檢視監控狀況、評論與管理者維護的貼文、照片、影片，但不需要網站登入功能。

## 決策

在同一台 Ubuntu 監控主機執行動態 Python 網頁服務，直接讀取既有 SQLite 資料庫與媒體檔案。服務綁定 `0.0.0.0:8088`，由 Tailscale tailnet 提供網路存取；網站本身不實作登入。

## 後果

- 監控完成後，網站可立即讀取並呈現最新資料，不需靜態網站建置流程。
- 網站與監控程式共用資料目錄，部署與備份須維持資料庫及媒體檔案的一致性。
- 存取邊界由 Tailscale 管理；`0.0.0.0` 只代表主機監聽所有網路介面，並非網際網路公開網址。
- 網站不另行處理使用者帳號、登入或權限角色。
